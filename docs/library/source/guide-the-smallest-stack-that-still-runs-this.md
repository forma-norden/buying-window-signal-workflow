# The Smallest Stack That Still Runs This

> **Best for:** teams that want to operationalize buying-window signals without turning the system into a 12-tool sprawl.

## Why this page matters

The goal is not to collect every signal.

The goal is to make a small number of signals operational fast.

That requires just enough tooling to:

- detect the signal
- enrich the account
- route the motion
- send or warm the account
- measure the result

## Start with this stack

| Layer | Start here | Why it earns its place |
| --- | --- | --- |
| Signal capture | Sales Navigator, UserGems, Bombora, or a visitor-ID tool | You only need enough signal sources to prove the model |
| Enrichment | Clay | This is the layer that makes the signal routeable |
| CRM and routing | HubSpot or Salesforce | Ownership, scoring, and attribution start here |
| Sequencing | Instantly.ai or Smartlead | Triggered follow-up needs speed, not complexity |
| Social support | LinkedIn | Useful for warm-up and context, not as a substitute for routing |
| Measurement | CRM first, HockeyStack later | Prove the system before you overbuild attribution |

## Add later, not first

- advanced attribution
- extra enrichment providers
- account scoring layers you cannot operationalize yet
- more signal sources than the team can route cleanly

## Why this is enough

It solves the core operating problem:

1. detect the event
2. qualify the account
3. identify the right contact
4. route the motion
5. measure whether the signal created pipeline

That is enough to prove the model before you add more complexity.

## The routing questions to answer first

1. Which signals actually matter for our ICP?
2. Who owns each signal once it lands?
3. What score activates outbound, ABM, LinkedIn, or monitoring?
4. What has to be enriched before anyone writes copy?

If those four answers are unclear, buying more tools will not help.

## Do not ignore the inbox layer

Signal quality does not rescue bad sending infrastructure.

If the inbox layer is weak, the best signals still die on missing or unreachable contacts.

## How teams waste it

Buy too many tools before the route logic is clear.

If your team cannot answer which signals matter, who owns them, what score activates them, and which route each one triggers, more software will not fix the system.
