# When to Reach Out, Six Buying Signals Worth Routing First

This guide is built for teams that want sharper timing with less outbound waste.

## The Six Signals

1. champion job change
2. new executive hire
3. pricing-page return traffic
4. hiring signal around process pressure
5. review-site intent
6. adjacent stack change

## Practical Rule

Every signal still needs:

- ICP fit validation
- confidence scoring
- route selection

The signal alone is never enough.

## Output Expectation

For each signal, generate:

- score
- route
- owner
- first move
- follow-up checkpoint
