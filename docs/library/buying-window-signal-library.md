# The B2B SaaS Buying-Window Signal Library

Pilot resource for B2B SaaS GTM teams that want to prioritize the right accounts at the right time without adding SDR headcount.

## Start Here

Use this sequence:

1. score the signal
2. evaluate support context
3. assign route
4. trigger first move
5. log outcomes for iteration

## What You Get

- six buying-window signals worth operationalizing first
- a scoring model for outbound, ABM, LinkedIn warm, or monitor routes
- SOP-style execution guidance
- minimum viable stack guidance

## Why This Exists

Teams fail when signals hit weak systems:

- poor CRM state
- weak enrichment
- slow routing
- generic messaging
- no route logic

This library is the operating layer that closes those gaps.
