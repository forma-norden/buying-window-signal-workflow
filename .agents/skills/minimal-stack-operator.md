# minimal-stack-operator

## Purpose

Define and enforce the minimum tool stack required to run signal routing cleanly.

## Minimum Stack

1. signal capture source
2. enrichment layer
3. CRM and routing layer
4. sequencing layer
5. social support layer
6. measurement layer

## Decision Rule

Add tools only when the current stack fails a specific operating requirement.

No expansion if route logic, ownership, or scoring is still unclear.

## Output

- current stack audit
- minimum viable stack recommendation
- deferred tool list with criteria for later adoption
