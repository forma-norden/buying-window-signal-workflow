# new-executive-reset-play

## Purpose

Evaluate executive-hire events and route only valid opportunities.

## Inputs Required

- executive title
- start date
- account fit
- supporting context (hiring, stack, traffic, or none)

## Workflow

1. Confirm role relevance to buying committee.
2. Confirm recency threshold.
3. Evaluate support signals around the same function.
4. Route:
   - high fit plus support -> outbound now
   - high fit without support -> LinkedIn warm
   - weak fit -> monitor

## Output

- confidence score
- route
- first action
- rejection reason when monitored
